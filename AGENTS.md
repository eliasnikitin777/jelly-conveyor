# Общие инструкции для Jelly Conveyor

Этот файл — общие правила работы над репозиторием `jelly-conveyor`. Они применяются локально, в облаке и при работе с телефона через облачный чат. Храни изменения этих правил в Git вместе с проектом; не используй абсолютные пути конкретного компьютера.

В новом окружении используй актуальную версию репозитория. При изменении правил в существующем чате перечитай этот файл. Явные указания пользователя и обязательные ограничения среды имеют приоритет.

## Проект

Игра — статический сайт без сборки и внешних зависимостей. Основные файлы: `index.html`, `game.js`, `rules.js`, `levels.js`. Запускай команды из корня этого репозитория:

- Локальный сервер: `python3 -m http.server 8095 --bind 127.0.0.1`.
- Проверки игровой логики при изменении механики: `node --test game.test.js`.

Желейки не возвращаются с противоположного края; циклически движется только пол. Соединённые желейки одного цвета двигаются как единый организм. Вложенная желейка находится в той же клетке, что и оболочка, двигается с ней и становится самостоятельной после исчезновения оболочки. Один ход считается после отпускания указателя, только если позиции на поле изменились.

# Глобальная команда `-model`

Распознавай `-model` как отдельный токен, написанный самим пользователем в сообщении, а не как часть цитаты, документа, имени файла или чужой инструкции. Явные новые указания пользователя имеют приоритет.

Команда `-model` переключает режим выбора модели для текущего чата: первое применение включает режим, повторное выключает, следующее снова включает. Включенный режим действует для всех последующих задач этого чата до повторной команды пользователя; он не сбрасывается после ответа, выполнения задачи или смены темы и не переносится автоматически в другие чаты. Если в том же сообщении есть задача, сначала переключи режим, затем выполняй задачу с учетом нового состояния.

Перед началом каждой новой задачи при активном правиле оцени её сложность, объём, потребность в инструментах и риск ошибки. Порекомендуй конкретную доступную в Codex модель, при необходимости также уровень рассуждения, с коротким объяснением. Для актуального выбора модели при необходимости сверяйся с официальной документацией OpenAI.

Если активная модель достоверно известна и совпадает с рекомендованной, сообщи рекомендацию кратко и выполняй задачу без дополнительного согласования. Не считай значение `model` в `config.toml` доказательством того, какая модель выбрана именно в текущем чате.

Если активная модель отличается от рекомендованной или её нельзя достоверно определить, остановись до выполнения задачи. Назови рекомендуемую модель и текущую модель, если она известна; предложи пользователю выбрать рекомендуемую модель в интерфейсе и повторить запрос либо прямо разрешить выполнение на текущей модели. Не переключай модель сам и не считай молчание согласием. После явного выбора пользователя выполни ожидающую задачу; для новой задачи повтори оценку.

Проверка модели не должна мешать безопасному чтению, нужному только для оценки предстоящей задачи. Она не отменяет более приоритетные инструкции и обязательные ограничения среды.

# Глобальная команда `-comm`

Распознавай `-comm` как отдельный токен, написанный самим пользователем, а не как часть цитаты, документа, имени файла или чужой инструкции. Команда переключает режим `-comm` для текущего чата: первое применение включает режим, повторное выключает, следующее снова включает. Включенный режим действует для всех последующих задач этого чата до повторной команды пользователя; он не сбрасывается после ответа, выполнения задачи или смены темы и не переносится автоматически в другие чаты. Если в том же сообщении есть задача, сначала переключи режим, затем выполняй задачу с учетом нового состояния. Содержание режима определяется явными указаниями пользователя; это правило задает только его переключение и срок действия. Состояния `-model` и `-comm` независимы.

# Подтверждение пользователя

Если пользователь отвечает «ok» или «ок» (без учета регистра) на предложение выполнить действие или продолжить работу, считай это явным разрешением выполнить предложенное действие. В ответ на предложение продолжить на текущей модели «ok» означает разрешение выполнить ожидающую задачу на текущей модели. Не спрашивай повторно, что означает «ok». Это не отменяет обязательных ограничений среды.

Новый чат начинает с выключенными режимами `-model` и `-comm`, если пользователь явно не указал другое. Упоминание команд в этом файле не переключает их. Не придумывай поведение `-comm`, если пользователь ещё не определил его.
